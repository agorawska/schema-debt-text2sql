# schema-debt-text2sql
Text-to-SQL over Legacy Schemas with Technical Debt: An Experimental Study of General-Purpose LLMs under Human-in-the-Loop Correction

Anna Gorawska, Mateusz Bugajak
Silesian University of Technology, Gliwice, Poland

This repository will contain the experimental artifacts for the above paper, submitted to PVLDB (Experiment, Analysis & Benchmark track).

Status

All artifacts will be uploaded by November 1, 2026, together with the paper submission. 
They will include the annotated conversation logs of all 144 trials, the pruned schema DDL, the system and task prompts, the ground-truth queries, the corrective-feedback repository, the error taxonomy and annotation rubric, a synthetic data instance of the schema, and scripts to recompute all reported metrics, with step-by-step instructions.
